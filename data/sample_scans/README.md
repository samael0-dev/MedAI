# Sample Scans Directory

This directory is intended to hold sample medical scan files for testing and demo purposes.

## Supported Formats

### DICOM (.dcm)
Standard medical imaging format. Can be obtained from:
- [NIH Clinical Center Chest X-ray Dataset](https://nihcc.app.box.com/v/ChestXray-NIHCC)
- [TCIA (The Cancer Imaging Archive)](https://www.cancerimagingarchive.net/)

### Standard Images (.png, .jpg)
Pre-exported scan images. Can be sourced from:
- [Kaggle Chest X-ray Pneumonia Dataset](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)
- [Brain MRI Segmentation Dataset](https://www.kaggle.com/datasets/mateuszbuda/lgg-mri-segmentation)

### NIfTI (.nii, .nii.gz)
Neuroimaging format commonly used for MRI data.

## Demo Usage

Place sample files in this directory and they will be available for upload through the MedAI interface.

> ⚠️ **Important**: Do NOT commit real patient data to version control. Use only de-identified or synthetic datasets.
